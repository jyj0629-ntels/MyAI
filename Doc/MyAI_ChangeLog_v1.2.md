# MyAI Change Log v1.2

## Entry 1

- Added a lightweight question classifier to infer the theme, intent, urgency, and complexity of a user request.
- Added a provider selection service to map question type to likely suitable public AI providers.
- Added a minimal workflow engine foundation so tasks can run as step-by-step sequences.

## Why this matters

These changes are the first concrete step from generic prompt orchestration into a personal assistant workflow model, which matches the design requirement of step-by-step processing and better decision support.
